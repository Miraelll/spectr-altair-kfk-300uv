# Анализ спектра АЛЬТАИР КФК-300УФ

Программное обеспечение для управления однолучевым спектрофотометром «АЛЬТАИР» и анализа оптической плотности веществ. Разработано на C++ с использованием фреймворка Qt.

Программа обеспечивает связь с микроконтроллером спектрофотометра по последовательному порту (COM), управляет шаговыми двигателями монохроматора и аппаратно компенсирует ступенчатые переключения усиления (Gain) при сканировании.

## Основной функционал

* **Фотометрический режим:** Статичные измерения коэффициента пропускания (T, %) и оптической плотности (D) на фиксированной длине волны с возможностью многократных замеров.
* **Спектральный режим:** Автоматическое сканирование заданного диапазона длин волн (например, 190–500 нм) с заданным шагом. 
* **Аппаратная синхронизация Gain:** Интеллектуальный алгоритм перехвата базовой линии (`rezero`) и синхронизации физического множителя усиления (`ge 10`) для предотвращения разрывов графика на стыках светофильтров.
* **Защита от дрейфа:** Встроенный таймер контроля "свежести" базовой линии, предупреждающий оператора о возможном температурном дрейфе УФ-лампы (дейтериевой лампы) перед началом измерений образца.
* **Интерактивная визуализация:** Построение спектральных кривых в реальном времени с помощью `QtCharts`. Поддержка зумирования (колесиком мыши или выделением), всплывающих подсказок с точными координатами (x, y) и быстрого сброса масштаба (Ctrl+Z).
* **Экспорт данных:** Выгрузка полученных массивов (длина волны, пропускание, плотность) в формате CSV для дальнейшей обработки в Excel.

## Стек технологий

* **Язык:** C++ (стандарт C++17)
* **Фреймворк:** Qt 6 (или Qt 5)
* **Модули Qt:** `Core`, `Gui`, `Widgets`, `SerialPort`, `Charts`

## Интерфейс и эргономика

Интерфейс спроектирован с учетом минимизации ошибок оператора:
* Информативная статусная строка (Status Bar), отображающая текущее состояние прибора (ожидание, сканирование конкретной волны, завершение).
* Автоматическая блокировка элементов управления при отсутствии связи с прибором или во время активного сканирования.
* "Зебра" в таблицах для удобного чтения строк.
* Динамический опрос COM-портов при подключении/отключении USB-кабеля (Hot-plug).

## Протокол связи (Serial)

Программа отправляет текстовые команды (завершаемые `\r\n`) на скорости 115200 бод:
* `connect` — инициализация связи.
* `getwl` — запрос текущей длины волны.
* `resetdark` — калибровка и получение 8 уровней темнового тока.
* `swl <нм>` — перемещение монохроматора на заданную длину волны.
* `rezero` — зануление (blank) с автоматическим подбором оптимального Gain микроконтроллером.
* `ge 10` — запрос серии из 10 измерений для вычисления сырого сигнала.
